# Hi, I'm Chong-Wei Wang 👋

I'm an **M.S. student in Network Engineering** at **National Yang Ming Chiao Tung University (NYCU)**, working in the **Operating Systems and Computer Architecture (OSCAR) Lab**.

My interests include **operating systems, computer architecture, memory/storage systems, and CPU/GPU performance optimization**. My experience spans **backend software development, GPU-oriented research, and resource-efficient edge AI**. Previously, I was a research assistant in the **HPC Group at the National Center for High-performance Computing (NCHC)**.

## Technical Focus

- **Systems & low-level:** C, C++, Linux kernel, system calls, RISC-V assembly, Verilog RTL, QEMU, performance benchmarking
- **Software & backend:** Python, FastAPI, Docker, Git, GNU Make, JavaScript, API integration, RAG
- **Applied computing:** PyTorch, TensorFlow, PennyLane, 3D Gaussian Splatting, computer vision

## Selected Work

- **[CoachGPT — AI-Powered English Speaking Practice Chatbot](https://github.com/P-eterking/CoachGPT)**  
  Contributed to a multi-service LINE chatbot using **Python/FastAPI, Docker, RAG, speech transcription, and AI-driven NPC interactions**. Integrated webhooks and rubric-based feedback for university English-speaking practice.

- **[Splatting the Cat — 3D Virtual Try-On](https://doi.org/10.3390/electronics14193884)**  
  First-author research combining **3D Gaussian Splatting and view-decomposed LoRA** for 360° free-viewpoint virtual try-on, supporting different front/back garment inputs on a single **24 GB GPU**. *Electronics, 2025.*

- **[Resource-Efficient Plastic Classification](https://doi.org/10.1109/JSEN.2026.3689822)**  
  Developed an ML pipeline for **low-cost near-infrared sensing and edge AI**, using a dataset of **6,650 samples**; achieved **99.17% laboratory accuracy** and **75% field-test accuracy**. *IEEE Sensors Journal, 2026.*

- **[MPM-QIR — Quantum Image Representation & Compression](https://doi.org/10.1109/ICASSP55912.2026.11464301)**  
  First-author research on **parameter-efficient variational quantum circuits** for image representation and compression. *ICASSP Workshops, 2026.*
